# Royal Journey – gray theme (static site)
Plain HTML/CSS/JS, no build step.
- Deploy: push to GitHub, then Vercel > Add New Project > import repo (Framework: Other, no build command, output = root).
- Colors: edit the variables at the top of `assets/style.css`.
- Images: drop original photos into `assets/images/` using the same filenames as royalsetups.com (e.g. `visa-process.webp`); they appear automatically in gray.
- Contact form sends to WhatsApp (+971 56 7494755). Replace with Formspree/Vercel function if you need email delivery.
